# Skenario Demo 10 Menit

## Menit 1: Pembukaan
- Jelaskan judul proyek dan tujuan sistem.
- Tunjukkan stack: backend Python FastAPI, frontend JavaScript.

## Menit 2: Login dan Dashboard
- Login sebagai admin.
- Tunjukkan statistik dashboard.
- Jelaskan perbedaan route web dan API (/api).

## Menit 3-4: Manajemen Data Master
- Buka menu peserta, pembimbing, instansi.
- Tambahkan satu data baru untuk menunjukkan CRUD dasar.

## Menit 5-6: Absensi Wajah
- Buka halaman absensi.
- Aktifkan kamera.
- Lakukan registrasi wajah.
- Lakukan check-in wajah.
- Jelaskan confidence score dan status terlambat/hadir.

## Menit 7: Jurnal dan Penilaian
- Tambahkan jurnal kegiatan peserta.
- Buka modul penilaian, isi nilai peserta.

## Menit 8: Export Laporan
- Klik laporan PDF dan Excel pada sidebar admin.
- Tunjukkan file berhasil terunduh.

## Menit 9: Dokumentasi API
- Buka /docs.
- Perlihatkan endpoint penting (/api/face/*, /api/attendance/*, /api/reports/*).

## Menit 10: Penutup
- Jelaskan manfaat untuk Diskominfo.
- Sampaikan rencana pengembangan lanjutan (mobile app, notifikasi WA, GPS validasi).
